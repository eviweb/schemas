## [0.1.0] - 2026-11-24

### Added

- Add a canonical identifier for the initial external requirements schema revision.
- Add GitHub Actions validation for schema tests.
- Add optional provisioning sources with provider and exact reference fields.
- Initialize project documentation and repository configuration.
- Add a Draft 2020-12 schema for external executable requirements, validation fixtures and tests.
- Add tests for complementary schema validation and optional property mistakes.
- Add boundary tests for executable candidates and version declarations.
- Document manifest compatibility expectations and reproducible schema references.

### Security

- Update pytest to 9.0.3 to address PYSEC-2026-1845 in the test dependencies.
